# SurveyCraft Gaming Platform - Documentación Completa

## INFORMACIÓN GENERAL
**Nombre:** SurveyCraft Gaming Platform
**Descripción:** Plataforma web de encuestas sobre videojuegos con roles separados (Crafters y Players)
**Objetivo:** Sistema web para creación, respuesta y análisis de encuestas gaming con gamificación

## ARQUITECTURA TÉCNICA
**Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5.3, Chart.js, Thymeleaf
**Backend:** Spring Boot 3.1, Spring Security, Spring Data JPA
**Base de Datos:** Oracle SQL
**Herramientas:** IntelliJ, Git/GitHub, Postman

## MODELO DE BASE DE DATOS
### Tablas Principales:
- usuarios (user_id, username, email, password_hash, role_id)
- roles (role_id, nombre, descripcion)
- surveys (survey_id, titulo, descripcion, crafter_id, estado)
- questions (question_id, survey_id, pregunta_texto, tipo_pregunta)
- options (option_id, question_id, opcion_texto)
- responses (response_id, player_id, question_id, option_id)
- categorias, videojuegos, craft_tools

### Relaciones:
- Usuarios ↔ Roles (1:1)
- Crafters → Encuestas (1:N)
- Encuestas → Preguntas (1:N)
- Preguntas → Opciones (1:N)
- Players → Respuestas (1:N)

## SISTEMA DE ROLES
**CRAFTERS:** Crear/editar encuestas, ver análisis, exportar reportes
**PLAYERS:** Responder encuestas, ganar puntos, ver historial, subir de nivel

## FUNCIONALIDADES PRINCIPALES
- Autenticación y registro con selección de rol
- Panel Crafter: Dashboard, constructor encuestas, editor preguntas
- Panel Player: Encuestas disponibles, sistema respuesta, progreso
- Análisis: Gráficos interactivos, insights automáticos, exportación PDF
- Gamificación: Puntos, niveles, logros, ranking
